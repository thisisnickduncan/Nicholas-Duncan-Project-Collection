# Nick Duncan — Portfolio

Next.js + Tailwind + Framer Motion portfolio site.

To update content, edit `data/profile.ts` (bio, experience, education, contact links) and `data/projects.ts` (case studies — add a new project by copying an existing object in the array, no other files need to change). Search both files for `TODO` to find placeholder content that still needs replacing, including `public/resume.pdf`, which doesn't exist yet.

```bash
npm run dev    # local dev server
npm run build  # production build
```
